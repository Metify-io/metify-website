Metify Blog CMS

This page becomes the TinaCMS visual editor once TinaCloud is connected.

Setup Instructions

  1. Go to app.tina.io and sign in with GitHub
  2. Create a new project and connect the Metify-io/metify-website repo
  3. Copy your Client ID and Token
  4. Add these as Vercel environment variables:
    NEXT_PUBLIC_TINA_CLIENT_ID
    TINA_TOKEN
  5. Update the build command to: npm run build:cms
  6. Redeploy — the CMS editor will appear here

Local development: Run npm run dev:cms to edit content locally with the CMS.
